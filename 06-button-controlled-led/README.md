# Button Controlled LED

A simple Arduino project where an LED turns **ON when the button is pressed** and **OFF when the button is released**.

## Components

- Arduino
- LED
- Push button
- Resistor
- Breadboard
- Jumper wires

## What I learned

- `pinMode()` — sets the LED and button pins as input/output.
- `digitalRead()` — reads the button's state.
- `digitalWrite()` — controls the LED.
- `if-else` — checks whether the button is pressed.

## How it works

- **Button pressed** → LED turns ON.
- **Button released** → LED turns OFF.
