# Serial Monitor Basics

A simple Arduino program that uses the **Serial Monitor** to display messages from the Arduino.

## What I learned

- `Serial.begin(9600)` — starts serial communication at 9600 baud.
- `Serial.println()` — prints a message to the Serial Monitor.
- `delay(500)` — waits 500 milliseconds before printing again.
